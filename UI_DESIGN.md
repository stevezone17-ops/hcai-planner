# UI and UX Specification

## Visual Direction
Build a premium AI productivity application inspired by modern products such as Linear, Notion, and Motion.

The interface should feel:
- professional
- intelligent
- calm
- modern
- focused

Avoid:
- generic Bootstrap dashboards
- excessive gradients
- excessive glassmorphism
- clutter
- giant decorative elements
- unnecessary animations

## Layout
Desktop:
- persistent sidebar
- compact top bar
- spacious content area

Mobile:
- responsive navigation
- stacked cards
- touch-friendly controls
- timetable adapted for narrow screens

## Pages

### Dashboard
Show:
- today's overview
- completion metrics
- today's schedule
- upcoming deadlines
- AI insights

### Tasks
Table/list with search, filtering, sorting, editing and status controls.

### AI Planner
Show:
- availability
- constraints
- preferences
- Generate AI Timetable button
- generation progress
- proposed schedule
- explanations

### Timetable
Day/week/month views.
Support drag and drop.

### Calendar
Calendar-style scheduling and deadline view.

### Analytics
Charts for productivity and Human-in-the-Loop metrics.

### Settings
Profile, availability, scheduling preferences, AI preferences, notifications, theme.

## Human-in-the-Loop Visual Language
Use clear badges:
- AI Suggested
- Accepted
- Modified by You
- Rejected
- Locked

The distinction must remain understandable without reading documentation.

## Interactions
Use subtle transitions for:
- task creation
- schedule generation
- drag and drop
- approval
- replanning
- notifications

Provide loading, empty, success, warning, and error states.
